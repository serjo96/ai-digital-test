# Shelf Ready — implementation note

**Status:** reproducible code baseline and local viewer; incomplete against the full assignment. Accepted B1-v2 accounts for all 220 rows as 156 canonical products over 216 product rows plus four non-products. Live AI was explicitly deferred by the user; generation and claim verification are not implemented. The stage 5 work delivers the independent UI/documentation portion without silently implementing stages 3–4.

**Architecture.** A Node 24 / TypeScript Nest standalone CLI reads the original feed and closed taxonomy. It normalizes prices as decimal strings with currency, extracts supported facts with source offsets, builds conservative compatible groups and reconciles conditions and rounding intervals. Offers retain supplier, SKU, stock and condition separately. Immutable run directories contain decisions, evaluation and metric history. React reads a prepared snapshot of that same result, validates source links, and displays products, review, offers, raw rows and evidence. It never performs matching or verification. An OpenAI provider adapter, structured extraction and live/replay cache are implemented and tested with synthetic transport; their runtime quality remains unmeasured.

**Three trade-offs.** (1) Conservative group compatibility preserves variants and accessories but leaves semantic matches unresolved. (2) Narrow deterministic extraction makes evidence and units inspectable but leaves 43 unparsed fragments; adding a model is a measured hypothesis, not demonstrated improvement. (3) Saved JSON and a read-only screen keep the project local and reproducible, while manual approval/editing, auth, deployment and a generalized feed platform are omitted.

**Evidence and failures.** Development matching is 17 TP, 0 FP, 0 FN: precision 17/17 and recall 17/17 on provisional labels, not a claim about all products. Review affects 64/220 rows and 51/156 products. Stage 5 control/repeat retain the exact B1-v2 decisions; wall time is 81.957/80.121 ms. Semantic additions remain 0/11. No generated descriptions or verifier metrics exist; holdout remains untouched and human label review is open. Earlier AI-assisted code lost the charging-case scope in USB-C Ladecase; source inspection found it and B1-v2 preserves it. During UI integration, review references could point outside the selected product; the viewer now includes related review sources. More details and commands: [stage 5 report](docs/STAGE5_REPORT.md), [AI usage](AI_USAGE.md).
